Assessment Questions & Answers

I created this website using plain HTML, CSS, and Bootstrap 5, hosted on Netlify. I chose these tools for their simplicity and fast deployment. Bootstrap provided responsive layout and clean styling without needing a complex build process. I stored my code in a public GitHub repository and linked it directly to Netlify for continuous deployment.

One challenge I faced was an error while pushing my files to GitHub (“author identity unknown”). I fixed it by configuring my Git username and email using Git commands (git config --global user.name and git config --global user.email). After that, I successfully deployed to Netlify.

Netlify is very user-friendly. The automatic deployment from GitHub commits saves a lot of time and effort. I was impressed by the clarity of the dashboard and how fast builds complete even for first-time users.

For improvement, I think it would help beginners if Netlify displayed short “probable cause” hints for build failures. This would make troubleshooting easier without digging through full logs.

Troubleshooting steps:

  • Check build logs from the top to find the first actual error message.
  • Verify build command, publish directory, and environment variables in Site Settings → Build & Deploy.
  • Check for lockfile mismatches (npm vs yarn) and dependency errors.
  • Clear cache and redeploy to ensure no stale files cause issues.

301 redirect rule (_redirects file):

/netlify/*  https://www.google.com/search?q=:splat  301

Proxy redirect rule (added to _redirects or netlify.toml):

/api/*  https://httpbin.org/:splat  200

These redirect rules tell Netlify to permanently redirect requests or proxy them to another service.

I created a simple function in netlify/functions/hello.js:

export const handler = async () => {
  return {
    statusCode: 200,
    body: JSON.stringify({ message: "Hello from Netlify Functions!" })
  };
};

The function worked on first try and responded correctly at /.netlify/functions/hello. I also tested with a custom redirect path (/api/hello) and it returned JSON successfully.
